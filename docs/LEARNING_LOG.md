# ASCEND — Evidence gap 1: End-to-end SQL analytics project

**Discover:** Investigate public CDC PLACES data, identify a unit of analysis and define three measurable questions connected to Woke & Rooted.

**Reflect:** What can I *show* that I built? What is a source measure versus a transformation? How could I accidentally confuse modeled estimates with actual patient records?

**Explain:** Use `COUNT(*)`, `GROUP BY`, `JOIN`, `CASE`, CTEs and windows to explain each calculation to someone without an analytics background.

**Apply:** Download source, validate, run queries, interpret with caveats, publish a documented GitHub repository and an evidence-based story brief.

## Evidence for skills matrix
- **Explain:** README, methods and SQL annotations.
- **Build:** data pipeline, SQLite model, analytical queries and output.
- **Validate:** automated tests, relational integrity assertions, null/range/uniqueness checks.
- **Teach:** write a short explanation of one query and discuss its pitfalls in a public post.
